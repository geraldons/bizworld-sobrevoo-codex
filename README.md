# BizWorld · sobrevoo Codex

Demonstração cinematográfica de 10 segundos renderizada em Three.js, em 1920×1080 a 30 fps.

Este repositório contém somente o vídeo, uma capa e uma página de reprodução. Não contém o código ou os recursos 3D do jogo. A publicação não concede licença de reutilização dos materiais.
